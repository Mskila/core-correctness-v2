# 非核心归档

`extras/` 只保存 Core Correctness V2 之前的研究快照，便于追溯，不属于可发布的
训练、回测、实时信号或产物流程。

- `experiments/`：旧 group/V1 回测、checkpoint 检查、特征试验、一次性诊断脚本
  及硬编码旧机器路径的启动器。
- `history/`：旧训练、回测、推送和仓库说明记录。

这些文件不会被正式入口导入，也不参加核心依赖、CI 门禁或当前能力声明。它们可能
依赖已拒绝加载的旧产物、旧路径或已移除的分组训练语义，因此仅供阅读；不要将其
输出包装成 V2 策略。旧 checkpoint 和策略本身仍须保留，不能删除或静默兼容。
